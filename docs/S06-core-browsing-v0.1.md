## 逻辑与交互

- 主题和分区切换、关键词提交、类型切换、器械/肌群/项目筛选。
- 同维度多选取并集，跨维度取交集；排除草稿；按名称、别名和简介匹配关键词。
- 条件写入 URL，支持刷新、分享及浏览器前进后退。
- 主题页按钮与侧栏主题链接遵循相同的条件保留规则；跨主题时仅重置原主题分区。
- 全站搜索弹窗发起新的全站检索；主题搜索旁的全站扩展操作保留关键词和适用条件。
- 桌面下拉立即应用；手机弹出抽屉，点击应用才提交，取消保留原条件。
- 切到非动作类型时清除器械与肌群并提示；有条件时支持逐项移除、清除字段筛选和重置页面。
- 详情结构保留来源 URL 与滚动位置；切换预览类型后仍可回到原列表。
- 键盘焦点可见；搜索和筛选使用原生 dialog；支持 Escape、搜索快捷键 `/` 和减少动效偏好。

## 实现中的修正

1. 窄屏首页的大标题曾发生四行折行，挤压按钮区域。改为两条明确标题行、视口相关字号及自适应高度。
2. 返回来源列表最初只保留了 URL，滚动位置归零。实测复现后补充来源滚动上下文和回归测试，浏览器复测恢复到原位置。
3. 搜索或筛选提交后定位到列表控制区域；切换主题时展示新主题页顶部。
4. 仅有关键词时不展示无实际作用的“清除筛选”；关键词可以独立移除，手机也提供重置入口。
5. 独立审查发现历史遍历没有记录离开前的最新滚动位置：增加按历史条目 ID 保存的内存坐标，并在当前页刷新前回写位置。
6. 首页锚点曾覆盖历史恢复：新锚点导航与刷新/返回恢复分别处理，避免强制跳回主题区。
