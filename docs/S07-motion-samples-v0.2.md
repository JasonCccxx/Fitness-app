# S07｜三个 3D 动作样本 v0.2

日期：2026-10-26。状态：三个可交互 3D 样本和 GIF 预览已制作；专业动作审核未进行，尚未纳入正式教程资料库。

## 范围

- 徒手深蹲：下肢复合动作，观察髋膝配合与足部位置。
- 俯卧撑：水平推动作，观察支撑点与整体起落。
- 哑铃弯举：单关节负重动作，观察屈肘、上臂与器械跟随。
- 独立页面：`/motion-lab/index.html`。原始教程数组仍为空。
- 播放控制：暂停/继续、0.25×/0.5×/1×、进度拖动、关键阶段、正面/侧面/斜侧、相机重置。
- 导出：GLB 模型下载、当前视角 40 帧/4 秒/640×480 GIF 下载。

## 来源与制作

人体和骨骼从 OpenGym3D 的 CC0 MakeHuman 基础中提取，保存于 `site/source-assets/human-base.glb`。原始上游动画已去除。没有把上游深蹲和弯举的 Mixamo 动画重新分发。

三个样本由 `site/scripts/build-motion-samples.py` 重新生成；它使用 NumPy 计算刚体变换与双骨骼逆运动学，保留骨段长度，烘焙为每个动作 97 个关键帧、4 秒循环。弯举器械为本项目程序生成，附着在手部骨骼上。当前不展示肌肉激活、受力百分比或精确关节角度教学。

模型来源、输入散列和许可见公开素材目录内的 `provenance.json` 与 vendor 的许可文件。工程检查见 `build-report.json`，它仅检查骨骼长度和循环衔接，不代表专业动作审核通过。

重新生成：安装 Python、NumPy 后运行 `python site/scripts/build-motion-samples.py`。预览：`node site/server.mjs`，打开本地 `/motion-lab/index.html`。

## 后续制作前需要决定

1. 人体风格：当前统一中性材质的人体是否保留，还是改为运动服、简化模型或更清楚的关节标记。
2. 表达方式：真人视频、预渲染动画和交互式 3D 的分工；哪些动作值得提供自由视角。
3. 教学标准：示范者、审核者、适用范围、替代动作和术语。
4. 动作质量：专业复核关节轨迹、活动范围、支撑接触、肩胛与手部表现；当前为运动学近似。
5. 性能：正式内容制作时再压缩人体网格与动画，测量目标设备首次加载速度。
