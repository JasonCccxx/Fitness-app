# S02｜分类与内容结构 v0.1

日期：2026-10-19  
依据：[S00—S01 产品说明](product-brief.md)、用户提供的 GPT 对话 archive、本轮“不制作具体动作和训练模板”的要求。  
状态：本步骤设计文档已完成；以下为后续页面设计的工作基线，尚未进行网站实现。

## S02.1 分类方案与取舍

采用“主题探索入口＋统一资料库＋多维字段”。主题组织浏览体验，内容独立存在，跨主题复用。

| 方案 | 取舍 |
| --- | --- |
| 主题入口＋统一资料库（采用） | 保留最初的探索构想，同时让用户直接检索；需要明确主题与字段的不同职责。 |
| 严格的主题树 | 容易理解，但同一内容可能归属多个主题，强制唯一归属会重复维护或遗漏内容。 |
| 只有统一资料库 | 检索路径较短，但削弱用户希望保留的主题探索体验。 |

主题不是互斥分类，也不表示内容适用性的专业结论。每条内容只有一个稳定身份，允许进入多个主题和分区。

## S02.2 主题与分区

首版规划三个主题。这里确定入口与结构，不承诺已具备对应内容。

| 主题 / 稳定标识 | 首版分区 | 分区含义 | 后续保留 |
| --- | --- | --- | --- |
| 健身房 Gym / `gym` | 力量训练 `strength`、有氧训练 `cardio` | 按用户在健身房的训练方向组织内容 | 攀岩入口；器械专题 |
| 户外 Outdoor / `outdoor` | 跑步 `running`、户外自重训练 `bodyweight` | 按户外活动与可用训练方式组织内容 | 徒步等其他户外项目 |
| 功能性训练 Functional / `functional` | 间歇训练 `interval`、循环训练 `circuit` | 按训练组织方式探索动作、指南与单次模板 | WOD 专题；专项技术内容 |

规则：

- 每个主题页先展示简要说明、分区入口和相关内容；分区切换直接更新内容区，首版不再增加一层必经页面。
- “全部分区”为默认状态。主题与分区均通过内容关联确定归属，不凭名称或器械自动猜测。
- 分区只是主题内的浏览集合。它们可以重叠，不充当全站通用的运动项目分类。
- 后续保留项记在设计文档中，当前主导航不展示一排尚无使用流程的入口。
- 攀岩未来按独立运动项目扩展，届时重新确认是否也值得拥有独立主题入口。
- Functional 是本网站采用的宽泛主题；不将它与 CrossFit 视为完全相同的概念。WOD 作为未来内容专题处理。

## S02.3 内容类型

| 类型 / 标识 | 用途 | 当前处理 |
| --- | --- | --- |
| 动作资料 / `exercise` | 介绍一个具体训练动作 | 确定字段、卡片与详情位置，正文及媒体待填 |
| 训练指南 / `guide` | 解释训练方式、器械或技术知识 | 确定基础结构，具体文章待填 |
| 单次训练模板 / `workout-template` | 安排一次训练的动作、顺序及参数 | 确定列表与详情位置，具体模板待填 |
| 多周训练计划 / `program` | 表达周期、训练日与进阶安排 | 后续扩展，当前不建列表、编辑器或完整结构 |

资料库规划“全部、动作、指南、训练模板”四个内容类型视图，使用同一列表框架。模板属于公开内容；个人创建和保存模板属于未来训练工具。

器械、肌群目前作为动作字段和筛选选项；不增加独立器械百科和肌群详情页。

## S02.4 字段与关联约定

### 通用内容字段

| 字段 | 说明 |
| --- | --- |
| `id`、`slug`、`content_type` | 稳定身份、可读路径和内容类型；修改显示名称不改变 ID |
| `title`、`aliases`、`summary` | 显示名称、可搜索别名、简要说明；界面语言后续确定 |
| `publication_status` | 草稿或已发布；草稿不进入公开搜索与详情 |
| `theme_links` | 关联主题及其分区，可多选；例如一条内容可出现在多个主题中 |
| `discipline_ids` | 运动项目；初始词表为力量训练、跑步、骑行、划船，随实际内容补充 |
| `environment_ids` | 适用环境，如健身房、户外、居家；与主题归属独立维护 |
| `training_format_ids` | 训练组织方式，如间歇、循环；允许为空 |
| `media`、`sources` | 媒体位置、替代文本及来源信息；当前预留字段 |
| `updated_at` | 最近修改时间，后续内容维护使用 |

“有氧”在本方案中属于训练方向，“自重”描述训练方式或负重条件，均不放入运动项目词表。新增词条前先确认它属于哪个维度。主题展示只由 `theme_links` 决定，不要求主题标签与环境字段一一对应。

### 各类型专属字段

| 类型 | 预留字段组 | 边界 |
| --- | --- | --- |
| 动作 | 器械、主要/次要肌群、动作模式、步骤、技术提示、常见错误、相关内容 | 具体说明与媒体待填；难度必须有项目内定义，当前不做全站统一难度筛选 |
| 指南 | 导语、章节、相关动作或模板 | 不强制提供肌群、器械或组数 |
| 单次模板 | 训练目的、适用说明、器械、可选预计时长、有序训练段、动作引用及参数、调整说明 | 参数结构须适合模板的运动类型；当前只保留结构，无具体训练安排 |

模板中的动作使用动作 ID 引用，允许附带该模板专用的提示。力量、跑步等不同训练段的参数在制作真实模板时细化，不用单一“重量×次数×组数”强制覆盖所有项目。

未来个人计划、执行记录独立于公开内容。到训练工具阶段再设计计划版本与历史记录保存，当前不预建完整数据表。

## S02.5 搜索与筛选

- 关键词匹配名称、别名和简介；预留中英文别名能力。首版不要求语义搜索、拼写纠正或全文检索正文。
- 通用条件：主题、运动项目、内容类型；主题页额外具有本主题分区条件。
- 仅“动作”视图显示器械和肌群筛选；切换到其他内容类型时移除这两类条件并提示已清除。
- 不同筛选维度之间取交集；同一维度多选取并集。缺少某字段的内容，不会命中对该字段的限定。
- 主题页搜索保留当前主题及分区，并明确显示范围；旁边提供“全站搜索”，转入资料库并移除主题、分区限定，保留关键词和仍适用的条件。
- 空关键词表示浏览当前范围；“无器械”是明确选项，缺失器械信息不等于无器械。
- 默认按维护的展示顺序排列，同顺序按稳定 ID 排列；当前不显示虚构的热门度、评分或个性化排序。

## S02.6 内容占位与状态

必须区分三种情况：

1. **内容待填充：**当前范围尚无已发布内容，说明“该部分内容正在准备”，展示可探索的其他范围。
2. **筛选无结果：**该范围已有内容，但当前条件没有匹配项，展示有效条件和清除入口。
3. **内容不可用：**路径不存在或内容未发布，展示内容不可用页及资料库入口。

所有内容尚未制作时，主题和资料库允许展示真实的待填充状态。设计稿可用标注清楚的卡片轮廓表达位置；这些轮廓不作为可搜索内容，不生成虚假数量、教学文字或可点击的假详情。详情结构通过设计稿或后续组件预览检查。

## S02.7 反驳意见与补充

- 保留三个主题是为了延续用户构想，不表示已经验证三个主题同样必要。之后若用户分不清 Gym 和 Functional，应优先修改文案或组织方式。
- 多维分类只减少重复维护，不能保证以后增加任何运动都不需要调整结构。
- 预留训练模板有助于未来衔接训练工具，但内容模板、个人训练计划、训练记录仍是三种不同对象。
- 本轮不填具体内容，因此只能检查分类规则与页面容量。真实内容能否准确归类、搜索是否好用，仍需填充后复验。
