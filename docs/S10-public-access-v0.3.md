## 当前访问方式

[打开 JY FITNESS ATLAS](https://jy-fitness-atlas-20261019.wellbat513.chatgpt.site/)。任何持有链接的人均可浏览，无需登录 ChatGPT，也不依赖开发电脑或本地服务运行。可直接将同一链接发送给手机或电脑上的测试者。

## 权限实现与验证

- 使用 Sites 原生访问设置，将 `access_mode` 从 `custom` 改为 `public`，保持原站点和网址。
- 原生工具确认策略修订为 `2`，时间为 2026-10-19 15:14:03 UTC，即日本时间 2026-10-20 00:14:03。
- 在此前未登录、只能看见登录页的测试浏览器中刷新，已经直接进入网站首页，确认匿名浏览可用。
- 这是托管访问设置的变更，没有修改页面、样式或内容，也没有增加账号、管理后台、数据库或训练数据功能。
- 公开访问仅开放网站浏览，不授予代码仓库或内容编辑权限。未来新增个人训练数据时需另行落实数据权限。

## 后续管理

该设置属于 Sites 的站点访问权限，和未来内容后台的管理员权限分别管理。后续若改回限定访问，应显式调整同一站点的访问策略，并重新验证允许与未允许用户的访问情况。
