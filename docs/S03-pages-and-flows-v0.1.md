# S03｜页面结构与操作流程 v0.1

日期：2026-10-19  
依据：[产品说明](product-brief.md)、[S02 分类与内容结构 v0.1](S02-classification-and-content-v0.1.md)。  
状态：本步骤的页面清单、文字线框和操作流程已完成；当前没有实现可操作网页。动作与模板只保留内容位置。

## S03.1 全站信息架构

```text
探索首页
├─ 健身房主题 → 力量 / 有氧
├─ 户外主题 → 跑步 / 户外自重
└─ 功能性训练主题 → 间歇 / 循环
         ↓ 主题内相关内容（统一列表组件）
统一资料库 ← 全站搜索
├─ 动作资料详情
├─ 训练指南详情
└─ 单次训练模板详情

后续：我的训练 → 个人计划 / 执行记录 / 进度
```

主题内的分区使用页面内切换，不要求用户连续经过“主题选择页—分区选择页—列表页”才能看到内容。所有入口复用同一内容实体及其详情页。

本轮只规划公开浏览，无需登录。未来“我的训练”记在信息架构中，当前不设置空白工具页或不可用的登录按钮。

## S03.2 页面与路径

路径是信息架构约定，具体实现方式在 S05 落实。

| 页面编号 | 页面 / 路径 | 主要职责 |
| --- | --- | --- |
| P01 | 探索首页 `/` | 说明网站用途、提供三个主题入口与全站搜索、提供直接进入资料库的路径 |
| P02 | 主题页 `/explore/{theme}` | 显示主题说明、分区切换、内容类型、当前范围内搜索和内容列表 |
| P03 | 统一资料库 `/library` | 提供跨主题的关键词搜索、类型切换和适用筛选 |
| P04 | 动作详情 `/exercises/{slug}` | 展示一条真实动作资料；当前仅定义结构 |
| P05 | 指南详情 `/guides/{slug}` | 展示一篇真实指南；当前仅定义结构 |
| P06 | 单次模板详情 `/templates/{slug}` | 展示一次公开训练安排及关联动作；当前仅定义结构 |
| P07 | 内容不可用 / 未知路径 | 清楚说明内容无法访问，提供资料库与首页入口 |

P02 和 P03 共用列表能力，不分别开发两套筛选逻辑。主题页的主题上下文固定，资料库的主题是可调整的筛选条件。

## S03.3 导航与文字线框

### 全站导航

- 桌面：标识/返回首页、探索、资料库、明确标为“全站搜索”的搜索入口。主题页可有主题切换侧栏；不增加无用途的第三栏。
- 手机：顶部保留页面身份和全站搜索入口；底部使用“探索、资料库”两个入口。主题切换放在主题页内，筛选在抽屉内展开。
- 详情页顶部提供回到来源列表的入口；从直接链接进入时返回资料库。
- 页脚可用一行文字说明“训练工具计划后续加入”，不设置无实际功能的“立即开始训练”按钮。

### P01 探索首页

```text
全站导航
网站用途说明 + 全站搜索
三个主题入口：主题名称 / 简短差异说明 / 进入主题
直接浏览资料库入口
页脚
```

首页的三个主题卡片不堆叠虚构的动作数量、用户数或热门榜。避免全屏选择页成为进入内容的强制步骤。

### P02 / P03 列表页

```text
页面标题 + 主题说明（主题页）/ 资料库说明
主题切换（主题页）/ 主题筛选（资料库）
全部分区 + 本主题分区（主题页）
全部内容 / 动作 / 指南 / 训练模板
搜索输入 + 明确的搜索范围
筛选入口 + 当前条件 + 结果数量
内容卡片列表 / 待填充状态 / 无结果状态
```

动作视图才出现器械与肌群筛选。内容卡片预留标题、类型、简介、少量适用标签、媒体位置；具体内容为空时用独立待填充区域，避免填满可点击的空卡片。图片缺失时使用清楚的类型标识，不显示破图或假的播放按钮。

### P04 / P05 / P06 详情页

| 共用区域 | 动作专属 | 指南专属 | 单次模板专属 |
| --- | --- | --- | --- |
| 返回来源、标题、类型、简介、适用标签、来源信息 | 示范媒体、器械与肌群、步骤、提示、常见错误 | 导语、章节正文、关联资料 | 目的与适用说明、器械、可选预计时长、有序训练段、关联动作、参数与调整说明 |

上述区域在设计稿中标为“待填充”。后续公开详情路由只对应已发布内容；无内容时通过设计稿或组件预览查看详情布局，不让空壳详情进入公开搜索。相关内容区域仅在存在真实关联时显示。

模板里的动作链接进入同一动作详情。返回模板时恢复来源位置。当前不提供“加入我的计划”“保存训练”“记录完成”等操作。

## S03.4 核心操作流程

### F01：按主题探索

1. 首页选择主题，直接进入默认“全部分区、全部内容”的主题列表。
2. 可切换分区，也可直接查看列表；切换到另一个主题时重置旧分区，保留仍适用的内容类型、关键词和筛选条件。
3. 选择内容类型或追加筛选，查看明确显示的当前范围。
4. 有真实内容时打开对应详情；没有内容时显示待填充状态。
5. 返回来源列表时恢复主题、分区、关键词、筛选和滚动位置。

### F02：直接查找

1. 在首页或全站搜索入口输入关键词并提交，进入资料库。
2. 新的一次全站搜索默认搜索全部主题、全部内容类型；结果页继续调整筛选。
3. 选择结果查看详情，再返回原搜索结果。
4. 在主题页的本地搜索框提交时保持主题及分区限制；选择“全站搜索”时移除这两项限制，保留关键词、内容类型和适用筛选。

“全部主题”只表示已发布内容的全站范围，不代表覆盖所有运动知识。

### F03：筛选与切换

1. 桌面选择条件后立即更新结果；关键词以提交为准。
2. 手机打开筛选抽屉，先编辑临时条件，点击“应用”后统一更新结果；取消或关闭不改变原条件。
3. 页面显示已生效条件，并允许逐项移除。
4. “清除筛选”移除附加字段条件，但保留关键词、内容类型及主题页范围；“清除关键词”单独移除搜索词。
5. “重置当前页面”回到该页面默认状态：主题页保留当前主题，恢复全部分区/全部内容；资料库恢复全主题/全部内容，二者均清空关键词和附加筛选。
6. 从动作切到其他类型时，器械与肌群条件移除，并给出简短提示；不在切回时暗中恢复旧条件。

不同维度取交集，同维度多选取并集，遵循 S02。切换主题或类型后仍存在但缺少匹配内容的有效条件不自动放宽；页面解释范围并提供清除入口。

### F04：查看训练模板及关联动作（内容填充后验证）

1. 在主题页或资料库选择“训练模板”。
2. 查看单次模板的目标、适用说明和训练段。
3. 进入其中某个关联动作，阅读动作信息。
4. 返回原模板及原位置。这个流程不创建个人计划，也不产生完成记录。

### F05：尚无内容

1. 进入尚无已发布内容的主题、分区或内容类型。
2. 显示“内容待填充”以及当前范围说明。
3. 提供切换分区、主题或进入资料库的可用操作。
4. 当前全站均无内容时仍明确说明状态；不暗示切换后一定能找到内容。

## S03.5 URL、返回与状态恢复

- 已提交的关键词、内容类型和有效筛选写入 URL；主题在主题路径中，分区在查询参数中。刷新、分享、浏览器前进后退恢复相同范围。
- 示例路径只表达结构，不代表已填内容：`/explore/gym?section=strength&type=exercise`、`/library?type=workout-template`。
- 详情保留站内来源上下文。首次直接打开详情时使用“返回资料库”，不猜测用户从哪个主题进入。
- 从列表进入详情后返回，恢复列表滚动位置；主动改变搜索或筛选时回到结果区顶部。
- 手机筛选抽屉的未提交条件不写入 URL。
- 已知筛选中出现无效值时移除无效项，并提示已调整；未知主题或详情路径进入不可用页。
- 首版样本规模不要求分页、无限滚动、复杂排序；真实内容规模增加时再补充相应规则。

## S03.6 异常、空状态与基本可用性

| 状态 | 页面行为 |
| --- | --- |
| 当前范围没有内容 | 内容待填充；不显示匹配成功的卡片或假数量 |
| 当前范围有内容，条件无匹配 | 显示筛选无结果、当前条件和清除操作 |
| 数据读取中 | 需要异步加载时显示加载状态，不能闪现“没有内容” |
| 数据读取失败 | 显示读取失败及重试入口，不归为零结果 |
| 内容不存在或尚未发布 | 内容不可用，提供资料库入口，不泄露草稿正文 |
| 图片或视频缺失 | 保持文字资料可读；媒体位置使用明确占位或隐藏 |

交互要求：表单有明确标签、卡片链接语义清楚、键盘可操作、焦点可见；手机抽屉关闭后回到触发按钮。具体视觉对比度、尺寸与动效在 S04 确定。

## S03.7 反驳意见与补充

- 不完全照搬 archive 的三层必经导航：额外的分区选择页会增加步骤，首版把分区和列表放在同页。
- 三个主题加资料库容易让用户误以为存在四份内容，因此页面必须明确当前范围，详情必须统一。
- 空白训练按钮不能证明扩展能力；预留信息架构、内容引用和模块边界更有价值。
- 所有内容待填时可以检查页面结构与状态设计，但无法验证教学可读性、真实搜索质量和模板可执行性。S06、S08 的相关验收须等真实内容填充后执行。
