# JY FITNESS ATLAS｜一页产品说明 v0.3

日期：2026-10-19 · 对应步骤：S00 产品定位与约束、S01 第一版范围与验收

本次更新：确定品牌与暗色视觉，落实本地交互原型；具体内容保持待填。历史摘要见 [v0.2](product-brief-v0.2.md)。

## 产品方向（S00）

**长期目标：交互式训练平台。当前目标：完成一个以主题探索为主、由资料库检索支撑的可交互样本网站，供体验、讨论和后续迭代使用。**

长期面向不同运动领域、不同训练水平的用户。本轮设计优先服务“希望探索不同训练方式，并逐步建立个人训练习惯的初级到中级用户”，尤其关注初学者能否理解主题、找到内容并看懂介绍。其他水平用户可以浏览；首版验收围绕上述优先人群展开。

本轮主要验证主题组织、内容查找与页面交互是否清楚好用。样本完成后再决定扩充方向；市场需求、训练习惯养成和长期留存仍需后续验证。

## 样本范围（S01）

| 项目 | 本轮任务 |
| --- | --- |
| 主题探索 | 规划 Gym、Outdoor、Functional 三个入口及其分区；主题允许交叉，通过统一内容关联组织浏览。 |
| 资料库 | 提供统一内容列表、关键词搜索和适用的分类筛选；主题入口与搜索结果指向同一份内容。 |
| 内容详情 | 展示名称、简要说明及该内容适用的结构化信息；字段和内容类型在 S02 确定。 |
| 交互体验 | 打通进入主题、查找内容、阅读详情、返回列表的流程；支持手机和桌面，包含无结果与清除筛选等状态。 |
| 内容占位 | 当前只确定字段和布局位置，具体动作、指南与模板后续制作；明确区分内容待填充与筛选无结果，不生成假搜索结果或教学内容。 |

**核心使用任务：用户带着兴趣或一个查找目标进入网站，理解可探索的方向，找到相关内容，并看懂其基本用途与信息。**

## 为训练工具保留的扩展位置

- **信息架构：**规划未来“我的训练”的位置及从内容进入训练工具的路径；当前导航展示可用功能，未来能力可通过简短路线说明表达。
- **内容结构：**内容使用稳定标识并与页面组件分离，支持跨主题复用；后续计划或记录可以引用已有内容。
- **功能边界：**浏览、内容和未来训练工具保持清楚的模块边界。开发训练系统时，再落实计划与实际记录分离，以及不同运动的专属指标。

本轮暂缓账号、云端收藏、训练编辑器、训练记录、进度面板、社区和 AI 功能。扩展准备限于必要的组织方式，完整的训练数据库和工具页面留待对应步骤设计。

## 完成标准与约束

1. 内容填充后，用户能通过主题浏览和关键词搜索两条路径找到样本内容，筛选实际改变结果。
2. 列表与详情信息一致；手机和桌面均能走完核心流程，主要可见操作有实际反馈。
3. 新增一条相同类型的内容可通过结构化数据完成，无需复制整张详情页。
4. 样本版与未来功能的边界清楚，当前展示与实际可用能力一致。

本轮暂不规划内容运营、完整维护后台、成本测算和商业化。涉及样本内容的基本准确性、素材来源和可用性，随样本制作处理。

已实现首页、三主题、资料库、检索筛选、内容结构预览和训练路线，使用轻量静态页面与本地 Node.js 服务。具体训练内容、账号与训练工具尚未加入。真实用户试用和真实内容下的验收仍待进行。
