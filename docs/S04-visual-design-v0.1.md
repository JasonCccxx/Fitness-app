# S04｜视觉设计与交互样板 v0.1

日期：2026-10-19 · 品牌：JY FITNESS ATLAS

## 方向与取舍

沿用用户批准的主题探索、统一资料库和手机适配方向；用户授权本轮直接确定视觉细节并搭建。采用“暗色训练图谱”：炭黑背景、照片场景、暖白文字、黄绿色强调，保留参考对话中的运动科技感。

对比过的方案：纯终端资料站密度较高，初学者理解成本大；全屏动画主题世界会拖慢进入内容。当前采用有场景感的首页和简洁的资料页，优先保证导航、文字和可用操作。

## 视觉规范

| 项目 | 实施约定 |
| --- | --- |
| 背景 | 页面 `#0b0e0c`；侧栏 `#101410`；面板 `#151b16` |
| 文字 | 主文字 `#f3f4ed`；次文字使用足够明亮的灰绿，避免大面积低对比度细字 |
| 强调 | `#d5fa60`，用于主要按钮、选中状态、焦点和少量标题强调 |
| 字体 | 本机系统中文字体；英文大标题使用 Impact / Arial Narrow 等回退，避免依赖外部字体加载 |
| 布局 | 桌面侧栏约 224px，主内容有最大宽度；手机移除侧栏，使用顶部品牌和底部两项导航 |
| 图片 | 首页和主题页使用本地保存的场景图；照片只表达训练环境，不充当动作示范 |
| 组件 | 清晰边框、适量圆角、图标配文字、轻量悬停；不使用持续闪烁或强制全屏动画 |

## 页面实施

- 首页：品牌导航、宽幅主视觉、明确介绍、三主题场景卡片、资料库入口、未来训练工具说明。
- 主题页：紧凑场景横幅、主题切换、分区按钮、统一列表与筛选。
- 资料库：关键词、类型切换、适用筛选、当前条件标签及真实空状态。
- 详情结构：动作、指南、模板各自保留结构，通过明确标识的预览入口访问，不创建假内容。
- 训练路线页：解释当前阶段和未来工具方向，避免不可用的“开始训练”按钮。

## 交互

- 桌面侧栏使用当前页面高亮；手机底部仅保留探索与资料库。
- 全站搜索弹窗与主题内搜索的范围明确区分；支持 Escape 关闭，关闭后恢复焦点。
- 桌面筛选立即应用；手机抽屉先编辑、再应用，取消不更改 URL。
- 已生效条件写入 URL，刷新、分享和前进后退保持一致。
- 焦点可见；遵循减少动效偏好；手机筛选抽屉考虑键盘焦点管理。

## 内容边界与验收

无真实动作、指南、模板时显示“内容待填充”，不伪造条目、数量、排行榜、收藏或用户数据。具体内容以后填充。当前可检查导航、布局、搜索范围、筛选状态与详情结构；真实检索质量与训练用途留待内容准备后验证。
