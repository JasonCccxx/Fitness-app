## 安全检查说明

所有十张业务及版本表启用 RLS。Supabase 顾问剩余提示是有意设置的边界：`private` 表无客户端策略且撤销直接权限；公开身份判断函数仅返回当前调用者布尔值；需要提升权限的 RPC 内部核验已登录身份、角色及所有权。不能为了消除提示而向私人角色表添加公共策略。

Google 发布状态、品牌核验和后续自有域名配置见 [工程说明](S05-backend-auth-v0.4.md)。访问统计目前覆盖已登录用户的页面、内容浏览和计划保存事件，不代表全体匿名访客流量，也不记录私人计划正文。长期保留策略、账号删除自助流程和正式运营隐私说明留待上线运营配置。

本轮验证后台与集成，不代表三个动作的专业审核或真实用户试用已经完成。
