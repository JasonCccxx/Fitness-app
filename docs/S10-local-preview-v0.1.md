# S10｜本地部署与试用交付 v0.1

日期：2026-10-19 · 本轮部署方式：本地预览，无需域名。

## 地址与启动

本次交付的本机入口：[JY FITNESS ATLAS](http://localhost:4173)。运行服务时可在浏览器访问，工程已经保存在本机项目目录。

日后重新启动：双击项目根目录 `启动网站.cmd`。需要 Node.js 22 或以上；本机当前有 v24.13.0。也可在项目目录执行：

```powershell
node site/server.mjs
```

默认只监听 `127.0.0.1:4173`，终端按 Ctrl+C 停止；关机后需重新启动。端口已被使用时先检查已有页面，或使用 `--port 4174` 启动另一个端口并访问对应地址。

## 小范围试用

- 同一台电脑：使用上述本机链接，让参与者完成 [S08 任务](S08-user-testing-v0.1.md)。
- 同一 Wi-Fi 的手机或电脑：停止本机模式，在 `site` 中运行 `node server.mjs --host 0.0.0.0`，用打印出的 `Network` 地址访问。
- 不同网络的参与者：需要托管测试链接或其他明确的访问方案，当前本机链接无法直接分享给外网用户。

本轮没有修改系统防火墙、路由器设置或创建外网隧道；局域网访问没有代替用户设备进行验证。

## 关于 GPT / Sites 和正式域名

用户允许本地或 GPT 上测试，本轮选择本地完成并验证。项目的静态目录为 `site/dist`；以后可以另行迁移至测试托管地址，正式域名不属于当前运行的必要条件。本轮没有创建或发布远端 Site，因此没有远端访问地址。
