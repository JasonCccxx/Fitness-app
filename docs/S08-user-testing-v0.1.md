# S08｜小范围用户试用方案 v0.1

日期：2026-10-19 · 状态：试用材料已准备，尚未进行真实用户试用或收集反馈。

## 试用范围

当前适合检验：主题是否容易理解、导航和搜索范围是否清楚、筛选交互是否顺手、用户能否分辨内容待填和页面错误。当前不适合检验：真实搜索质量、教学质量、模板可执行性和训练习惯养成。

可先邀请 3—5 位愿意参与的潜在用户，优先包含初学者与有一定训练经验的人。每人约 10—15 分钟，记录使用设备。此人数用于发现问题，不代表统计意义上的需求验证。

## 主持方式

先让用户自行探索，不提前讲解按钮位置。向用户逐项朗读任务描述，观察其路径；右侧预期表现留给主持者。卡住约 90 秒时可提供帮助，并记录帮助内容。无需用户实际进行任何身体训练。

## 当前即可执行的任务

| 编号 | 给参与者的任务 | 主持者观察与预期 |
| --- | --- | --- |
| T01 | 看看首页，说说这个网站是做什么的，目前可以做什么。 | 能理解主题探索与资料库，知道这是内容待填的预览版，不误以为可记录训练。 |
| T02 | 你想了解健身房中的力量训练，请找到相应区域。 | 从主题卡片或导航进入 Gym，再选择力量分区；允许不同合理路径。 |
| T03 | 你想按器械查动作，请选择哑铃，并再选择一个肌群。 | 先进入动作视图，找到器械和肌群条件；条件显示在页面及 URL 中。 |
| T04 | 手机上再试选一个器械，但改变主意，不保存这次更改。 | 打开筛选、修改、取消；原条件和 URL 保持不变。 |
| T05 | 保留兴趣方向，改看看训练指南。你觉得原来的器械筛选会怎样？ | 类型切换清除动作专属条件并提示；观察用户是否理解。 |
| T06 | 搜索“跑步”，并确认你是在某个主题中搜索，还是在全部主题中搜索。 | 能区分主题内搜索、扩展全站和顶部新全站搜索；内容待填不被理解为请求失败。 |
| T07 | 找到训练模板的页面结构预览，再回到你刚才的列表。 | 识别这是结构预览；返回后保留条件和位置，不误认为已获得可执行训练安排。 |
| T08 | 刷新当前列表，再用浏览器后退，看看浏览条件是否符合预期。 | URL 状态恢复，历史导航与用户预期一致。 |
| T09 | 如果以后想记录训练，你会去哪里了解相关功能？ | 能发现训练路线说明，理解它属于后续计划。 |

## 内容填充后再执行

- 找到一个符合指定器械条件的真实动作，解释其主要信息。
- 用正式名称和别名查找同一内容，观察是否能辨认一致身份。
- 从真实单次模板进入关联动作，再返回模板原位置。
- 提交不会匹配的关键词，判断无结果提示和清除操作是否清楚。

每次试用后问三点：最不清楚的词是什么；最难找到的入口是什么；下一次访问最希望完成什么。不要只问“好不好看”。

优先修复阻断任务、条件丢失和范围误解；视觉偏好单独记录。尚未发生的用户反馈不可写成结论。
