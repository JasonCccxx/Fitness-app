## 实现方法

1. 保持 `site/dist` 的页面、样式和交互不变，复制为根目录 `dist` 进行打包。
2. 保存 `.openai/hosting.json`，配置静态目录与 SPA 回退，支持直接访问或刷新主题、资料库等路由。
3. 检查项目后，由官方 helper 将同一份前端、服务代码、测试与 docs 提交并推送至 Sites 配套 Git 仓库。
4. 使用推送后核实的完整 commit SHA 和对应静态压缩包保存版本并发布。
5. 检查托管平台返回的最终状态与地址，成功后停止原本机预览服务。

网站由托管平台提供，不依赖当前电脑开机。源文件仍保存在本机，便于后续编辑。此轮没有配置用户个人 GitHub 仓库、持久内容数据库或训练数据存储。
