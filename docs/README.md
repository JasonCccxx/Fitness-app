## 后续修改规则

- 保持 S00—S11 编号稳定，具体讨论可定位到文档内的子编号，例如 S02.2 或 S03.4。
- 每完成一个步骤，在 `docs` 中保存带版本号的步骤文档。修改已完成步骤时保留旧版，另建新版本，并更新本索引的有效版本链接。
- 产品主说明作为当前摘要更新版本号；详细分类与流程以对应步骤文档为准。
- 修改时记录原因和影响范围；涉及上游定位、内容类型或页面职责时，同步检查关联步骤。
- 当前网站代码在 `site` 中，具体动作、训练指南和训练模板尚未制作。结构原型完成不等于真实内容和真实用户验证完成。
